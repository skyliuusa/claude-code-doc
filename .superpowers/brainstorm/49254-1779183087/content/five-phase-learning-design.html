5 阶段学习设计

目标：同时建立架构理解、复刻能力和安全判断，而不是只记 README 里的功能名。

Learning Architecture
01

边界

区分事实、推断和不可验证内容。

02

主架构

CLI 入口、终端 UI、状态和上下文。

03

工具层

工具注册、权限、风险分类和审批。

04

Agent 层

子 Agent、多 Agent、记忆和主动模式。

05

复刻

抽象成自己的最小 CLI Agent 设计。

每阶段固定问题

  • 这个模块解决什么用户问题？
  • 它依赖哪些下层能力？
  • 如果自己实现，最小版本是什么？
  • 它带来哪些安全风险？

学习产出

  • 一张模块关系图
  • 一份术语和机制索引
  • 一套最小复刻蓝图
  • 一份安全检查清单
